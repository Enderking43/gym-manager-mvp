## Fase 9: Módulo de Punto de Venta (Buffet), Inventario y Control de Gastos

### 9.1. Base de Datos (`src/database/db.js`)
IMPORTANTE: Crear las tablas usando `CREATE TABLE IF NOT EXISTS` para no afectar los datos actuales.
- [ ] **Tabla `articulos`:** `(id INTEGER PRIMARY KEY, nombre TEXT NOT NULL, precio REAL NOT NULL, stock INTEGER NOT NULL DEFAULT 0, estado TEXT DEFAULT 'Activo')`.
- [ ] **Tabla `ventas_articulos`:** `(id INTEGER PRIMARY KEY, articulo_id INTEGER, cantidad INTEGER, precio_unitario REAL, total REAL, fecha TEXT DEFAULT CURRENT_TIMESTAMP, usuario_id INTEGER)`. (Con FK a articulos y usuarios).
- [ ] **Tabla `egresos`:** `(id INTEGER PRIMARY KEY, concepto TEXT, monto REAL, fecha TEXT DEFAULT CURRENT_TIMESTAMP, usuario_id INTEGER)`. (Con FK a usuarios).

### 9.2. Main Process y Handlers IPC (`src/main/handlers.js`)
- [ ] **Inventario (ABM):** Crear handlers `obtener-articulos` (trae todos los activos), `crear-articulo`, `actualizar-articulo` (actualiza nombre, precio o suma stock), y `eliminar-articulo` (hace un borrado lógico: `UPDATE estado = 'Inactivo'`).
- [ ] **Venta de Buffet:** Crear handler `registrar-venta-articulo(articulo_id, cantidad, usuario_id)`. **CRÍTICO:** Debe usar una transacción (`BEGIN/COMMIT`). 1) Verificar que haya stock suficiente. 2) Insertar en `ventas_articulos`. 3) Descontar el stock en `articulos` (`UPDATE stock = stock - cantidad`). 
- [ ] **Gastos:** Crear handler `registrar-egreso(concepto, monto, usuario_id)`.
- [ ] **Dashboard Financiero:** Actualizar `obtener-estadisticas-dashboard` para que ahora retorne:
  - `caja_cuotas_diaria`: Lo que ya estaba.
  - `caja_buffet_diaria`: SUM de `ventas_articulos` de hoy.
  - `egresos_diarios`: SUM de `egresos` de hoy.
  - `rentabilidad_neta_diaria`: (Cuotas + Buffet) - Egresos.
  - `productos_mas_vendidos`: Un array con el TOP 5 de artículos más vendidos en el mes (GROUP BY articulo_id, ORDER BY cantidad total DESC).
- [ ] **Preload:** Exponer todos los nuevos handlers en `preload.js`.

### 9.3. UI Administrador - Inventario y Gastos (Solo Admin)
- [ ] **Vista "Inventario Buffet":** Nueva sección en el Sidebar (usar `data-admin-only`). Debe tener:
  - Formulario para **Dar de Alta** nuevo producto (Nombre, Precio, Stock inicial).
  - Tabla con el listado de productos activos.
  - Botones en la tabla para **Editar** (abre modal para cambiar precio o agregar stock) y **Eliminar**.
- [ ] **Vista "Gastos/Egresos":** Nueva sección. Formulario simple para cargar un gasto (Concepto y Monto) que use el `usuario_id` actual. Tabla inferior mostrando los gastos cargados hoy.

### 9.4. UI Administrador - Punto de Venta (Todos los roles)
- [ ] **Vista "Punto de Venta / Buffet":** Nueva sección en el Sidebar visible para Empleados y Admins.
  - Diseño estilo POS: Una grilla (Grid) de tarjetas grandes, una por cada artículo disponible que tenga `stock > 0`. Cada tarjeta muestra Nombre, Precio y Stock disponible.
  - Al hacer clic en una tarjeta, abrir un modal rápido que pregunte "Cantidad" (por defecto 1, máximo el stock actual), calcule el total y tenga un botón "Cobrar". Al confirmar, llama a `registrar-venta-articulo` y muestra un toast de éxito.

### 9.5. UI Administrador - Dashboard y Reportes
